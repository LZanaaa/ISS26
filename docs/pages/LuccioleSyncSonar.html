Firefly Sync A + B

Introduction

Definere un modello qak di un sistema firefly che simula il comportamento di 3 lucciole sincronizzate fra loro.

Requirements

Costruire il simulatore di un sistema costituito da 3 lucciole. Inizialemente, le lucciole lampeggiamo ciascuna con una frequenza (costante) propria.
  1. Dopo 10 secondi le lucciole devono lampeggiare in modo sincronizzato
  2. Il sistema è dotato anche di un sonar . Quando il sonar rileva un ostacolo a una distanza minore di una distanzaprefissata DMIN, le lucciole devoono lampeggiare in modo sincronizzato. Quando la distanza dell’ostacolo(ri)supera DMIN, le lucciole tornano a lampeggiare in modo random.

Requirement analysis

A

  • Sistema a 3 attori che interagiscono via eventi flash(ID)
  • La strategia di convergenza si basa sull'osservazione di una lucciola "master" da parte delle altre "observer".
  • Le lucciole "observer" sincronizzano il loro ciclo interno quando ricevono l'evento dalla lucciola "master", tramite lo stato handleFlash.
  • Questo sistema è di facile implementazione, seppur presenta un unico punto di fallimento (la dipendenza dalla lucciola "master").

    Event sonarData : sonarData( DISTANCE )

B

Il sonar è un attore che genera dati su una determinata distanza
  • Il sonar è modellato come un'entita observable
    • 
        QActor sonar_mock context ctx_requirements {
            State s0 initial {
                // Emette una distanza d < DMIN
                emit sonarData : sonarData( 50 ) 
            }
        }
  • La lucciola è modellata come entità observer ed aggiorna il proprio ciclo interno in base al dato osservato
    • 
        QActor firefly_logic_check context ctx_requirements {
            State random_mode initial { } 
            Transition t0 whenEvent sonarData -> check
            
            State check {
                onMsg( sonarData : sonarData(D) ) {
                    [# val D = payloadArg(0).toInt() #]
                    // Se d < DMIN, passa alla modalità sincrona
                }
            }
            Goto sync_mode if [# D < 100 #] else random_mode

            State sync_mode { }
            Transition t1 whenEvent sonarData -> check
        }
