Differential Drive Robot

Introduction

Requirements

Costruire un sistema software che comanda un Differential Drive Robot (DDR) in modo che, 
partendo dalla posizione iniziale HOME, il robot si sposti lungo il perimetro di una stanza rettangolare vuota. 
Il DDR si deve fermare quando tornato in HOME.

Il DDR è anche sensibile ai dati rilevati da un Radar.
Quando il Radar rileva un 'intruso' a una distanza minore di una distanza prefissata ``DMIN``:
  
  - se il DDR si sta muovendo , il DDR si ferma fino a che il Radar non rileva più un 'intruso' così vicino 
  - se il DDR è fermo in HOME, il DDR ruota su sè stesso fino a che un 'intruso' così vicino scompare

Requirement analysis

  1. Il sistema deve essere rappresentato con un modello qak, il cui nome è ddrsys
  2. Il ddrsys dev'essere rappresentato da un attore qak (ddr), che ciclicamente passa dallo stato fermo a quello di movimento e viceversa
    3. 
System ddrsys

Context ctxddrsys ip [ host="localhost" port=8040 ]

QActor ddr context ctxddrsys {
    State s0 initial {
        //Descrizione del comportamento dell'attore
    } 
}
  3. Il ddr dopo aver percorso il perimetro della stanza si ferma quando rileva di essere in HOME
  4. Il ddr è sensibile ai dati rilevati da un radar, il radar è modellato come attore qak che a intervalli di tempo regolari invia messaggi di segnalazione al ddr, se vi è o no un intruso a distanza minore di DMIN
    5. 
System ddrsys

Context ctxddrsys ip [ host="localhost" port=8040 ]

QActor radar context ctxddrsys {
    State s0 initial {
        //Descrizione del comportamento del radar
    } 
}
  5. Quando il ddr riceve un messaggio di ostacolo e si trova in movimento, si ferma fino a che l'ostacolo non è più presente, ossia quando riceve dal radar che non vi sono ostacoli a meno di DMIN
  6. Quando il ddr è fermo in HOME e riceve un messaggio di intruso, ruota su sè stesso fino a che l'intruso non è più presente
